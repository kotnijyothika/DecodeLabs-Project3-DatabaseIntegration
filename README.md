# DecodeLabs Project 3 - Database Integration

## Project Overview
This project was developed as part of the DecodeLabs Full Stack Development Internship.

It is a database integration project that connects the backend server with MongoDB for persistent data storage.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript

## Features
- Database connection
- Student schema design
- CRUD operations
- Input validation
- Data storage and retrieval
- Error handling

## API Endpoints
- POST /students
- GET /students
- GET /students/:id
- PUT /students/:id
- DELETE /students/:id

## Files Included
- server.js
- package.json
- config/
- models/
- routes/
- controllers/
